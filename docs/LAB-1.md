# LAB 1 — WORDPRESS E-COMMERCE SETUP

## Objective
To understand content management systems by establishing a baseline e-commerce store using WordPress and WooCommerce.

## Requirements
- WordPress Installation.
- WooCommerce Plugin Configuration.
- Addition of distinct project categories.
- Creating sample products with descriptions and prices.
- Demonstration of the Shop and Checkout flows in WordPress.

## Tools
- WordPress
- WooCommerce
- Local PHP/MySQL Server (e.g., XAMPP/WAMP/Local)

## Implementation & Procedure
Since Mithila Ghar transitioned to a custom React/Node.js stack for its primary application, this requirement was fulfilled utilizing a separate, existing WordPress instance.
1. Installed WordPress via XAMPP.
2. Downloaded and activated the WooCommerce plugin.
3. Created categories such as 'Mithila Foods' and 'Handicrafts'.
4. Added 3-5 sample products ensuring prices were correct.
5. Set WooCommerce payment gateways to accept 'Cash on Delivery' for testing.
