# LAB 2 — BASIC e-COMMERCE WEBSITE

## Objective
To develop the frontend architecture and essential navigation for a bespoke e-commerce application avoiding CMS rigidity.

## Requirements
- Professional Homepage focusing on Terai and Mithila Culture.
- Product categories and catalog view.
- Basic routing (Home → Shop → Product → Cart → Checkout).

## Tools
- React.js
- Vite
- Vanilla CSS (`global.css`)
- React Router DOM

## Implementation & Procedure
1. Initialized a React application using Vite.
2. Structured navigation components (`Header.jsx`, `Footer.jsx`).
3. Created a modern style sheet (`global.css`) employing variables, fluid typography, and CSS Gradients to mirror the Mithila aesthetic without utilizing heavy frameworks.
4. Created stub components for `Home.jsx`, `Shop.jsx`, and `ProductDetail.jsx`.
5. Connected all routing paths in `App.jsx`.

## Result
A static footprint of Mithila Ghar was generated. Users can browse the homepage, select products, and see dynamic product details populated from the layout.

## Conclusion
Building a dedicated SPA (Single Page Application) with React allows for finer control over UI components and routing transitions compared to a standard multipage CMS, paving the way for advanced custom requirements.
